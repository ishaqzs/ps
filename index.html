Component library

Atlas UI ships a large set of ready‑to‑use components with consistent tokens and behavior, designed for business workflows.

Foundations & inputs

  • Buttons: primary, secondary, subtle, destructive, icon‑only, loading states.
  • Typography: text, headings, labels, code, with semantic variants.
  • Form field: label, description, error, hint, and layout wrappers.
  • Inputs: text, number, textarea, select, checkbox, radio, switch.
  • Date & time: date picker, range picker, time input, timezone‑aware display.
  • Upload: file dropzone, progress, validation feedback.

Theming & tokens

Atlas UI uses a token‑based theme system built on CSS variables, enabling brand customization, light/dark modes, and per‑tenant overrides.

  • Design tokens: color, typography, spacing, radius, shadow, motion, z‑index.
  • CSS variables: exposed under --atlas-* for runtime overrides.
  • Theme object: strongly typed in TypeScript for editor autocompletion.
  • Dark mode: class‑based or media‑query‑based switching with smooth transitions.
  • Per‑app themes: wrap dashboards in <AtlasThemeProvider> with custom tokens.
// Example: theme typing
export interface AtlasColorScale {
  50: string;
  100: string;
  200: string;
  300: string;
  400: string;
  500: string;
  600: string;
  700: string;
  800: string;
  900: string;
}

export interface AtlasTheme {
  primary: AtlasColorScale;
  accent: AtlasColorScale;
  neutral: AtlasColorScale;
  radius: { sm: number; md: number; lg: number; pill: number };
  shadow: { soft: string; strong: string };
}

declare module "atlas-ui" {
  export function AtlasThemeProvider(props: { theme: Partial<AtlasTheme>; children: React.ReactNode }): JSX.Element;
}

Internationalization

Built‑in i18n support lets teams ship internal tools in many languages without rewriting components. Atlas UI integrates cleanly with popular libraries like react-i18next.

  • Language context: <AtlasI18nProvider> exposes current locale and helpers.
  • Translation keys: components use stable keys, not hard‑coded strings.
  • Plural & formatting: delegates to i18n engine for pluralization, dates, numbers.
  • SSR‑friendly: hydration‑safe language loading for Next.js and other SSR frameworks.
  • Fallbacks: graceful fallback to default locale when translations are missing.
// Example: using Atlas UI with react-i18next
import { useTranslation } from "react-i18next";
import { Button } from "atlas-ui";

function SaveButton() {
  const { t } = useTranslation("common");
  return <Button variant="primary">{t("actions.save")}</Button>;
}

Repository structure

The repo is organized to keep components, docs, and tests aligned. If an existing structure is present, Atlas UI extends it rather than replacing it.

  • packages/atlas-ui: core component library (React + TypeScript).
  • packages/atlas-theme: shared tokens, CSS variables, and theme helpers.
  • apps/docs: documentation site with live examples and playgrounds.
  • tests: unit tests (Jest / Vitest) and visual regression (Storybook / Playwright).
  • .storybook: optional Storybook setup for component‑level exploration.
